Environment check

kubectl get nodes

Apply only the broken lab

cd labs/resource-lab-01

Workload inspection

kubectl get deployment -n resource-lab-01

Pod investigation

kubectl describe pod -n resource-lab-01
kubectl get events -n resource-lab-01 --sort-by=.metadata.creationTimestamp

Node resource inspection

kubectl get nodes
kubectl describe node kind-control-plane

Manifest inspection

kubectl get deployment resource-demo -n resource-lab-01 -o yaml

Requests and limits

kubectl get deployment resource-demo -n resource-lab-01   -o jsonpath='{.spec.template.spec.containers[0].resources}{"\n"}'

kubectl get pod -n resource-lab-01   -o jsonpath='{.items[0].status.qosClass}{"\n"}'
