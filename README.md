Probes Study

Purpose

Review Kubernetes probes through a short concept explanation, reference examples, inspection commands, and one broken troubleshooting lab.

Study order

1. Read concept.md
2. Review the files in examples
3. Review inspection-commands.md
4. Initialize Git from this directory
5. Preserve the untouched broken lab in the first commit
6. Apply only labs/probes-lab-01/manifests
7. Investigate before editing any manifest
8. Complete investigation.md
9. Commit the investigation
10. Fix the lab
11. Create solution-and-verification.md
12. Commit the final solution

Important

The example manifests are for reading only.
Do not apply the examples unless they are explicitly needed.
The lab is intentionally broken.
Do not edit the lab before completing the investigation.
