# ConfigMap Study

This project covers the Kubernetes ConfigMap concept through short notes, examples, inspection commands, and a broken troubleshooting lab.

## Structure

- concept.md: Core concept explanation.
- examples/: Small ConfigMap usage examples.
- inspection-commands.md: Useful inspection and troubleshooting commands.
- labs/lab-01-broken/: The untouched broken lab.

# Study Order

1. Read concept.md.
2. Review the files in examples/.
3. Review inspection-commands.md.
4. Start labs/lab-01-broken/.
5. Investigate before changing any YAML.
6. Record findings in investigation.md.
7.  Commit the investigation separately.
8.  Fix the lab and verify the result.
9.   Create solution-and-verification.md after the fix.
10. Commit the final solution separately.
